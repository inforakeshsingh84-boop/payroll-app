PF / ESI / Tax 🔖
Deduction rules aur rates
🏦 Provident Fund (PF)
✅ Wage Ceiling mode: PF hamesha ₹15,000 pe calculate hoga
Employee PF = ₹15,000 × 12% = ₹1,800
⚠ Basic/Gross mode mein ceiling field disabled hai — PF full amount pe lagega (no cap)
Note: PF = Basic × Employee Rate. Employer contribution bhi salary cost mein add hoti hai.
🏥 ESI (Employee State Insurance)
Note: Agar employee ka gross ₹21,000 se zyada hai toh ESI applicable nahi hogi.
📑 TDS / Income Tax Slabs
New Regime Slabs:
Up to ₹3,00,000Nil
₹3L – ₹7L5%
₹7L – ₹10L10%
₹10L – ₹12L15%
₹12L – ₹15L20%
Above ₹15L30%
⚙ Salary Structure %
Gross = Basic + DA + HRA + Other Allowances

📊 PT Slabs (Gross Salary based)

Notification Settings 🔔
Email aur SMS alert configure karein — Absent / Leave par Reporting Manager ko notify karo
📧 Email Notifications (EmailJS)
📋 Setup Steps:
1. emailjs.com par free account banayein
2. Email Services → Gmail/Outlook connect karein → Service ID copy karein
3. Email Templates → New Template → In fields ko set karein:
  • To Email: {{to_email}}  ← Zaroori hai!
  • Subject: {{subject}}
  • Body mein: {{to_name}} {{emp_name}} {{message}} {{date}}
4. Account → API Keys → Public Key copy karein
⚠ Template mein "To Email" field mein {{to_email}} likhna ZAROORI hai — warna email nahi jayegi
📱 SMS Notifications (Fast2SMS)
📋 Setup Steps:
1. fast2sms.com par free account banayein
2. Dashboard → Dev API → API Key copy karein
3. Wallet mein minimum ₹10 add karein (1 SMS ≈ ₹0.25)
4. API Key yahan paste karein
⚠ CORS Notice: Fast2SMS direct browser calls par CORS error aa sakta hai. Production mein ek simple backend proxy use karein ya CORS proxy enable karein. Test ke liye corsproxy.io use kar sakte hain.
